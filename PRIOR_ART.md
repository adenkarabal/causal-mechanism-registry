# Prior Art

### Neighbouring lines of work

Named so that a reader can place the registry quickly. The scan is search-level. Additions and corrections go through the [prior-art issue template](.github/ISSUE_TEMPLATE/prior-art.yml).

| Line | Where it sits relative to this registry |
|---|---|
| Mechanism catalogues in analytical sociology | Theory-first and open-ended: an entry enters because a theorist argues for it. Here entries are corpus-first, gated on recurrence and irreducibility, and closed within a version. |
| Financial ontologies and causal knowledge graphs | They extract causal statements written in the documents. These mechanisms are read judgmentally and often appear in a case that never names them. An ontology also carries no state; these entries exist to be scored. |
| Compact state representations for language models | There the state is ground truth inside a task or a simulated environment. Here it is a reading of the real world, which is why every signature carries refutation conditions and an expiry date. |
| Ontology- and schema-guided prompting | Those constrain the model's output. This loads its input state. |
| Structured analytic techniques in intelligence analysis | Those adjudicate between competing hypotheses. A signature describes one state. |
| Layered machine-readable research artifacts | Those carry a paper's claims. This carries a standing state on a cut-off schedule. |
| Phase classification with public bulletins, such as the IPC | The nearest relative: a closed vocabulary, a severity scale, an evidence bar, a dated public record. It classifies outcome severity; this names the mechanisms producing it. |

Not yet read against this work: composite risk indices in humanitarian and disaster response, event-coding vocabularies, conflict early-warning frameworks, and the forecasting-accountability literature.
